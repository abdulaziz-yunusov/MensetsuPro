# MensetsuPro - Roles and Permissions

## 1. Guest (Unregistered User)
**Permissions:**
- **View:** Home Page, About, FAQ, Contact, Terms, Privacy Policy.
- **View:** List of Interview Questions, Categories, Learning Materials (preview only).
- **View:** Public Blog Posts, Community Discussions (read-only).
- **Action:** Sign Up, Login, Forgot Password.
- **Restrictions:** Cannot perform mock interviews, cannot view full question answers/tips, cannot post completely on the community or blog, cannot save/bookmark items.

## 2. User (Registered & Authenticated)
**Permissions:**
- **All Guest permissions.**
- **Profile:** Edit personal profile (name, target role, Japanese level, avatar).
- **Interview Questions:** View full details (sample answers, tips, mistakes), save/bookmark questions.
- **AI Interviewer:** Configure and start AI mock interviews, answer text/voice, receive and view AI feedback/history.
- **Learning Materials:** Access full materials, mark as read/watched.
- **Coding Practice:** Access coding editor, run test cases, save progress.
- **Community:** Create discussion threads, reply to threads, like/upvote, report inappropriate content.
- **Blog:** Write and publish blog posts to user blogs, comment on others' blogs.
- **Dashboard:** View progress tracking, analytics of own learning.

## 3. Admin (Platform Administrator)
**Permissions:**
- **All User permissions.**
- **Dashboard:** Access Admin Dashboard for global analytics (active users, popular questions, etc.).
- **User Management:** View all users, edit user roles, ban/suspend users.
- **Question Bank:** Add, edit, delete interview questions and categories.
- **Learning Materials:** Add, edit, delete curated materials (books, videos, articles).
- **Moderation:** Delete inappropriate discussion threads, comments, or blog posts. Hide or flag content.
- **System:** Modify platform settings, edit FAQ content manually, manage tags and categories.
