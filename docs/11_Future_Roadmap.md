# MensetsuPro - Future Improvements Roadmap

## Phase 1: MVP (Months 1-2)
- Basic user authentication (Email/Password & NextAuth).
- Static Question Bank with categories and search.
- Curated Learning Materials static lists.
- User Profile Dashboard (saving questions, basic progress tracking).

## Phase 2: Core Platform & AI Integration (Months 3-4)
- **AI Interviewer Module**: Text-based mock interviews using OpenAI.
- Grading and feedback system generation.
- Community and Blog functionality (basic CRUD for posts/threads).
- Admin Dashboard for content management.

## Phase 3: Advanced Features & Audio/Video (Months 5-6)
- **Voice/Speech Mock Interviews**: Integration with Web Speech API and Whisper API to allow users to speak their answers.
- **Coding Practice Environment**: Implementation of a basic browser-based code execution environment (e.g., using specialized APIs like CodeX or JDoodle, or isolated WebAssembly runners).
- Gamification elements: Streaks, badges for completing interviews or hitting question milestones.

## Phase 4: Expansion & Monetization (Months 7+)
- **Premium Tier**: Offer detailed, human-reviewed interview feedback or unlimited AI video interviews for a premium subscription (Integration with Stripe).
- **Live Peer-to-Peer Mock Interviews**: Allow users to pair up and interview each other via WebRTC.
- **Company Portals**: specific portals for companies to post actual interview assignments.
- **Mobile Native Apps**: Convert the platform into a React Native app for iOS and Android.
