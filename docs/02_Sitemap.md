# MensetsuPro - Sitemap

## Public Pages
- **`/`** - Home Page
- **`/about`** - About the Platform (Short explanation, team, mission)
- **`/faq`** - FAQ Page (How to use the platform, pricing, AI details)
- **`/contact`** - Contact Us Page
- **`/terms`** - Terms of Service
- **`/privacy`** - Privacy Policy

## Authentication
- **`/login`** - User and Admin Login
- **`/register`** - Sign Up / Registration
- **`/forgot-password`** - Password Recovery

## Interview Preparation
- **`/questions`** - Interview Questions Directory
  - **`/questions?category=[id]`** - Filter by category
  - **`/questions/[id]`** - Individual Question Details (sample answers, structure, tips)
- **`/ai-interview`** - AI Interviewer Setup
  - **`/ai-interview/session/[id]`** - Active AI Interview Session
  - **`/ai-interview/results/[id]`** - AI Interview Feedback & Score

## Learning & Practice
- **`/materials`** - Curated Learning Materials (Videos, books, articles)
  - **`/materials/[id]`** - View embedded video or reading material
- **`/coding-practice`** - Coding Practice Hub
  - **`/coding-practice/[id]`** - Individual coding problem editor and test cases

## Community & Content
- **`/community`** - Discussion Forum / Threads
  - **`/community/thread/[id]`** - Individual discussion thread
- **`/blog`** - Platform Blog & User Articles
  - **`/blog/new`** - Create new blog post (User/Admin)
  - **`/blog/[slug]`** - Read individual blog post

## User Dashboard (Protected)
- **`/dashboard`** - Overview, Progress, Recent Activity
- **`/dashboard/profile`** - User Profile (Name, Photo, Target Role, Japanese Level)
- **`/dashboard/saved-questions`** - Bookmarked / Saved Questions
- **`/dashboard/mock-interviews`** - History of completed mock interviews
- **`/dashboard/bookmarks`** - Saved materials/videos
- **`/dashboard/my-blogs`** - Manage user-written blog posts
- **`/dashboard/settings`** - Account settings, notifications

## Admin Dashboard (Protected - Admin Only)
- **`/admin`** - Overview & Analytics
- **`/admin/users`** - Manage Users
- **`/admin/questions`** - Manage Interview Questions
- **`/admin/categories`** - Manage Categories
- **`/admin/materials`** - Manage Learning Materials
- **`/admin/moderation`** - Manage Discussions & Blog Posts
